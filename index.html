Musobaqa Qoidalari va Olimpiada Cheat-Sheet

Musobaqalarda eng ko'p qo'llaniladigan usullar, xatoliklar turlari va C++ hamda Python dasturlash tillari bo'yicha tayyor shablonlar.

Musobaqa Hukmlari (Verdicts)

  • AC (Accepted) — Yechim to'g'ri va barcha testlardan muvaffaqiyatli o'tdi!
  • WA (Wrong Answer) — Dastur natijasi namunaviy yoki maxfiy testga to'g'ri kelmadi. Chekka holatlarni (0, manfiy sonlar, katta sonlar) tekshiring.
  • TLE (Time Limit Exceeded) — Kod belgilangan vaqtdan (odatda 1.0 soniya) ko'p ishladi. Sikllarni optimallashtiring (masalan, O(N²) o'rniga O(N log N)).
  • MLE (Memory Limit Exceeded) — Ajratilgan xotiradan (odatda 256MB) ko'p xotira band qilindi. Katta massivlarni ehtiyotkorlik bilan e'lon qiling.
  • CE (Compilation Error) — Sintaksis xatolik! Kodingiz kompyuterda kompilyatsiya qilinmadi (nuqta-vergul, qavslarni tekshiring).
  • RE (Runtime Error) — Dastur bajarilish vaqtida to'xtadi (0 ga bo'lish yoki massiv chegarasidan chiqib ketish).

C++ Musobaqa Shabloni & Fast I/O

C++ da cin/cout sekin ishlashi mumkin. Buning oldini olish uchun Fast I/O satrlarini qo'shing:

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    // Tezkor kiritish/chiqarish (Fast I/O)
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    long long n;
    cin >> n;
    
    // Katta sonlar uchun long long ishlating!
    cout << n << "\n"; // endl o'rniga "\n" tezroq ishlaydi
    return 0;
}

Python Musobaqa Maslahatlari

Pythonda bir qatorda kiritilgan sonlarni o'qib olish va tezkor kiritish usullari:

import sys
# Tezkor o'qish uchun:
input = sys.stdin.readline

# Bitta qatordagi bir nechta butun sonlarni o'qish:
a, b = map(int, input().split())

# Ro'yxat (massiv) qilib o'qib olish:
arr = list(map(int, input().split()))

# Rekursiya chuqurligini oshirish:
sys.setrecursionlimit(200000)

JavaScript (Node.js) Musobaqa Shabloni

Node.js da musobaqa ma'lumotlarini (stdin) eng tez o'qib olish usuli:

const fs = require('fs');

function solve() {
    // Barcha ma'lumotlarni bir vaqtda o'qib bo'laklash:
    const input = fs.readFileSync(0, 'utf-8').trim().split(/\\s+/);
    if (!input || input.length === 0 || input[0] === '') return;

    const a = BigInt(input[0]);
    const b = BigInt(input[1]);
    console.log((a + b).toString());
}

solve();

  1. Masala shartini 2 marta to'liq o'qing: Cheklovlar ($1 \le N \le 10^9$) va turlarni aniqlang.

  3. Qoralama daftar: Kod yozishdan oldin qog'ozda misol testni qo'lda hisoblab ko'ring.
